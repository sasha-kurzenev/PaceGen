# Пробный мелодичный рок-фрагмент

Этот эксперимент превращает события из чистого TypeScript-генератора в MIDI и WAV. Выбранный пользователем источник гитары — WAV-сэмплы FreePats CC0 из [звукового эксперимента](../guitar-spike/README.md). Воспроизведение не обращается к сети. Готовые файлы лежат в `.expo/rock-demo/` и не входят в приложение.

## Создание

Из корня проекта:

```powershell
node experiments/rock-demo/export.mjs 20261105 120
python experiments/rock-demo/render.py .expo/rock-demo/fragment.json
```

Первый аргумент — uint32 seed, второй — целый BPM от 100 до 150. `fragment.json` содержит события и версию алгоритма; `fragment.mid` позволяет проверить аранжировку в секвенсоре; `fragment.wav` — офлайн-прослушивание. Для прослушивания на телефоне в той же Wi-Fi-сети:

```powershell
python experiments/rock-demo/serve_mobile.py
```

Открыть `http://<IP компьютера>:8766/`. Сервер отдаёт только страницу и WAV.

## Живое воспроизведение на телефоне

Из корня проекта:

```powershell
python experiments/rock-demo/build_live.py
python experiments/rock-demo/serve_live.py
```

Открыть `http://<IP компьютера>:8767/` в Chrome на Android. Это отдельная страница с Web Audio, которая выполняет скомпилированные модули `src/music/` прямо в браузере. Она загружает 11 коротких гитарных WAV и четыре существующих ударных сэмпла (всего около 1 МБ); затем меняет seed и создаёт следующие 32 такта без обращения к серверу. Темп 100–150 BPM выбирается ползунком, «Другая» меняет seed. Смена темпа или нажатие «Другая» во время игры запускают фрагмент с начала; непрерывный переход в конце 32 тактов не перезапускает звук.

Сервер на порту 8767 отдаёт только пробную страницу, скомпилированные JS-модули и сэмплы. Он нужен для первого открытия страницы, но уже открытая страница продолжает играть и генерировать музыку без сети. Страница показывает счётчик опоздавших событий и задержку таймера; эти показатели не заменяют профилирование Android. Для локальной быстрой проверки при установленном Playwright: `python experiments/rock-demo/check_live.py`; флаг `--long` также проверяет автоматический переход после 32 тактов.

Локальная проверка Chromium с `--long` прошла: после загрузки сеть была заблокирована, «Другая» и смена темпа продолжали работать, автоматический переход показал новый seed на первом такте, опоздавших событий было 0. Это результат компьютера, а не Android-телефона.

## Состояние

- 32 такта 4/4, 65 секунд при 120 BPM, шесть разделов от вступления до окончания.
- Повторяемый восьминотный мотив в A minor с вариациями; гармония, ведущая и ритм-гитара, бас, ударные формируются отдельно.
- Гитарные ноты имеют струну и лад; удары гуманизированы по времени и громкости.
- WAV использует выбранные гитарные сэмплы, предварительную обработку и существующие ударные приложения. Бас пока простой синтезатор, а ударные не роковые акустические: тембры и сведение требуют прослушивания и доработки.
- WAV — настольный офлайн-рендер для музыкальной оценки; живая страница использует Web Audio и похожую, но не идентичную цепочку обработки. Измерения CPU, памяти, батареи, фонового воспроизведения и 30-минутный тест на Android ещё не выполнены. Аудиоадаптер нового ядра в основное приложение пока не подключён.
